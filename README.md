# Privacy Analyser

A web application developed during my **internship at Tegel Consulting**, as part of a school group project. The project focuses on analysing and presenting privacy-related data in a clear and structured way. It explores how application behaviour and data handling can be visualised to support better understanding of privacy considerations.

Built during FED24 at Medieinstitutet, with emphasis on front-end development, UI structure, and safe API integration.

## 🔹 Features

- Privacy Analysis Overview: Displays analysed privacy-related data in a structured and readable format.
- API Integration: Fetches data from backend endpoints (stubbed in showcase branch for safety).
- Frontend-Focused Design: Clear layouts, reusable components, and consistent visual structure.
- Responsive Interface: Works across different screen sizes.
- Educational Focus: Explores privacy concepts and frontend–backend communication.
